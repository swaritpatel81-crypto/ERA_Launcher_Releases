## 💜 Welcome to ERA Launcher

**ERA Launcher** is a modern Minecraft launcher designed to bring together Minecraft launching, mod discovery and profile management in one polished desktop application.

Inspired by the clean interface of modern gaming clients, ERA Launcher focuses on simplicity, customization and a smooth user experience.

Whether you're launching Minecraft, exploring new mods or managing your profile, ERA Launcher aims to make everything easily accessible.

**Your Minecraft journey starts with a new ERA.**

## ✨ Features

### 🎮 Minecraft Launcher

- Launch supported Minecraft versions.
- Simple and convenient game launching.
- Manage Minecraft installations.
- Clean launcher interface.

### 📦 Modrinth Integration

Discover Minecraft mods directly through the integrated Modrinth library.

- Search for Minecraft mods.
- Explore available mods.
